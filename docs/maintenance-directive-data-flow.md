# Data flow

Object page → maintenance directive RPC → persistent Weed Card or mowing rhythm state → canonical serving task → existing daily notification plan.

The directive supplies temporary title, instructions, crop links, checklist, assignee, date, and work window. It never records physical maintenance by itself.

Weed Card sessions and mowing events remain the physical-result evidence. Their append-only result inserts close only those directives whose effect policy has been satisfied.
