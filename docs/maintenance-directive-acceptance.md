# Acceptance target

From an Atlas object page, an Owner or manager can attach a temporary instruction or prerequisite to the object’s existing Weed Card or governed Mowing Card.

The saved work must:

1. Reuse the persistent maintenance identity.
2. Attach to the canonical object and selected crop cycles.
3. Assign the work to an active farm membership.
4. Stage the persistent card or prerequisite for a farm day and lockscreen window.
5. Preserve Weed and Mowing result semantics.
6. Remove the temporary instruction only when its selected result policy is satisfied.
7. Return the perpetual card to ordinary rhythm behavior afterward.
8. Keep ordinary release out of Bell history.
